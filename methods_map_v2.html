I · Препроцессинг

Подготовка данных

Любой ML-проект начинается с приведения данных к виду, пригодному для алгоритмов. В нашем случае — объединение трёх разнородных источников SCADA-телеметрии, журнала отказов и журнала статусов с разными временными шкалами.

merge_asof pandas

Нечёткое объединение временных рядов по ближайшему времени с допуском tolerance. В отличие от обычного merge, не требует точного совпадения временных меток.

Каждое событие отказа связывается с ближайшей записью SCADA

StandardScaler scikit-learn

Z-score стандартизация: каждый признак преобразуется к среднему 0 и дисперсии 1. Обязательно для линейных моделей, kNN, нейросетей; для деревьев формально не требуется, но даёт устойчивость.

x' = (x − μ) / σ
Признаки разного масштаба после Z-нормализации становятся сопоставимы

II · Разведочный анализ

Понять структуру данных

EDA отвечает на ключевые вопросы перед моделированием: каковы распределения, есть ли выбросы, как признаки коррелируют между собой, есть ли физически интерпретируемые различия между классами отказов.

Правило межквартильного размаха (IQR) статистика

Непараметрический метод поиска выбросов — не требует нормальности распределения. Точки вне интервала [Q₁ − k·IQR, Q₃ + k·IQR] помечаются как потенциальные выбросы. Стандарт k = 1.5 (правило Тьюки); для физических величин с тяжёлыми хвостами берут k = 3.0.

Анатомия boxplot: правило Тьюки 1.5·IQR
Документация и материалы
Wikipedia: IQR Wikipedia: Box plot seaborn boxplot NIST handbook
Корреляция Пирсона + иерархическая кластеризация статистика

Корреляция Пирсона измеряет линейную связь признаков. Иерархическая кластеризация группирует коррелированные каналы — это выявляет датчики одной подсистемы.

rX,Y = cov(X, Y) / (σX · σY) ∈ [−1, 1]
Дендрограмма: T₁..T₄ — температурный кластер

III · Балансировка классов

Когда отказов меньше, чем нормы

В исходных данных класс «нормальный режим» (NF) встречается в десятки раз чаще, чем любой класс отказа. Без балансировки модель «выгодно» научиться всегда предсказывать NF — формальная точность высока, но детектировать отказы такая модель не сможет.

SMOTE imbalanced-learn

Synthetic Minority Over-sampling Technique — генерирует синтетические объекты миноритарного класса через линейную интерполяцию между существующим объектом и одним из его k ближайших соседей того же класса. В отличие от простого дублирования, создаёт новые точки в пространстве признаков.

xnew = xi + λ·(xnn − xi), λ ∼ U(0, 1)
SMOTE интерполирует синтетические объекты на отрезках между ближайшими соседями
Документация и материалы
Chawla et al., JAIR 2002 imblearn docs Wikipedia MLM туториал
imblearn.pipeline + StratifiedKFold правильная схема

Принципиально важная связка. SMOTE применяется внутри кросс-валидации, только к обучающим фолдам. Если применить SMOTE до разбиения, синтетические объекты «протекут» в валидационный фолд и завысят оценку качества.

from imblearn.pipeline import make_pipeline
from sklearn.model_selection import StratifiedKFold

pipe = make_pipeline(
  SMOTE(random_state=42),
  StandardScaler(),
  LGBMClassifier()
)
cv = StratifiedKFold(n_splits=5, shuffle=True)
SMOTE применяется только к train-фолду каждой итерации
Документация и материалы

IV · Модели

Базовая модель и продвинутая

В работе сравниваются две модели: простое решающее дерево как базовая линия и LightGBM — современный градиентный бустинг, ставший де-факто стандартом для табличных задач.

Decision Tree базовая модель · scikit-learn

Иерархическая последовательность пороговых разбиений признакового пространства. На каждом узле выбирается признак и порог, максимизирующие чистоту разбиения по критерию Джини.

G = Σ pk·(1 − pk), где pk — доля класса k в узле
Структура дерева: корень → внутренние узлы → листья с классом

Главное преимущество — полная интерпретируемость каждого предсказания. Главный недостаток — склонность к переобучению без ограничения глубины.

Документация и материалы
sklearn user guide DecisionTreeClassifier Wikipedia KDnuggets
LightGBM Microsoft Research · продвинутая модель

Light Gradient Boosting Machine — ансамбль деревьев решений, в котором каждое следующее дерево исправляет ошибки предыдущего ансамбля (gradient boosting). Итоговое предсказание — взвешенная сумма всех деревьев.

F(x) = Σm=1..M αm·hm(x)
Каждое дерево учится исправлять ошибки ансамбля; финальное предсказание — линейная комбинация

Ключевые особенности:

  • Histogram-based learning — признаки дискретизируются в гистограммы (bins), радикально ускоряя обучение
  • Leaf-wise tree growth — дерево растёт по листу с максимальным приростом, а не по уровням
  • L1 / L2 регуляризация через параметры reg_alpha, reg_lambda
  • Поддержка пропусков и категориальных признаков «из коробки»
Документация и материалы
Ke et al., NeurIPS 2017 официальная документация Parameters tuning guide Wikipedia Gradient boosting
V · Валидация и оптимизация

Честная оценка качества

Чтобы получить честную оценку качества модели и подобрать оптимальные гиперпараметры, нужна корректная схема валидации. При несбалансированных классах обязательна стратификация — сохранение пропорций классов в каждом фолде.

StratifiedKFold scikit-learn

k-блочная кросс-валидация со стратификацией: данные разбиваются на k непересекающихся фолдов так, чтобы в каждом сохранялись пропорции классов. Модель обучается k раз (на k−1 фолдах) и оценивается на оставшемся. Итоговая метрика — среднее по k оценкам.

5-fold стратифицированная кросс-валидация
Документация и материалы
sklearn docs CV user guide Wikipedia
GridSearchCV scikit-learn

Сеточный поиск оптимальных гиперпараметров модели. Для каждой комбинации значений из заданной сетки выполняется кросс-валидация; выбирается комбинация с лучшей средней метрикой. В нашем проекте оптимизируется f1_macro — корректный выбор при несбалансированных классах.

param_grid = {
  'n_estimators': [6, 8, 16, 24],
  'num_leaves': [4, 6, 8],
  'reg_alpha': [1, 1.5],
  'reg_lambda': [1, 1.5],
}
grid = GridSearchCV(pipe, param_grid,
  cv=cv, scoring='f1_macro')

Подбираемые гиперпараметры LightGBM:

  • n_estimators — число деревьев бустинга
  • num_leaves — максимальное число листьев в дереве
  • reg_alpha / reg_lambda — L1 / L2 регуляризация

ROC-кривая (AUC) кривая качества

График TPR vs FPR при изменении порога классификации. Площадь под кривой (AUC) — мера ранжирующей способности модели, независимая от порога. AUC = 1 идеально, AUC = 0.5 случайно.

Precision-Recall кривая (AP) для дисбаланса

График Precision vs Recall. Average Precision (AP) — площадь под кривой. При сильном дисбалансе классов PR-AUC более информативна, чем ROC-AUC.

На что смотрит модель

Хорошая модель должна не только предсказывать, но и быть понятной: какие признаки на что влияют, в каких случаях модель уверена, а в каких сомневается.
